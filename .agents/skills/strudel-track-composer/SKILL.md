# Track composer
Start with a memorable motif. Develop through orchestration, counterpoint, silence, breakdown, harmonic shift, return and personal resolution. Inspect the real clock each turn. Avoid predetermined percentage-based song scripts; the model must decide based on ongoing music and timing. At 124 BPM a 600-second set has approximately 310 four-beat bars (600*124/240), not a hard stop. A reported bar is an estimate, not Strudel's exact scheduler. Save original source, all confirmed changes and the recording. Video 8 Switch Angel describes recording loops into Logic for later DAW arrangement; true isolated stems are not yet generated by this live engine.
