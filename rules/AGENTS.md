# AGY Strudel Live rules (v2)
Follow ../AGENTS.md and skills/strudel-live-performer/SKILL.md. The live Strudel daemon runs separately from the MCP process. Start the session with strudel_session_start, ask the user to unlock browser audio, and wait for session_status=running before evaluating any code. All musical changes go through strudel_eval and require browser ACK. The duration is a creative target, not a stopping timer. Keep checking elapsed, remaining and active_code; make original structural decisions. Use local vocal WAV/TTS via strudel_sample_import, strudel_vocal_play, or strudel_vocal_generate (same recorded bus). Finish with strudel_session_finish only after an actual musical epilogue. Do not use the previous fixed 15/35/65/85-percent preset schedule. If AGY does not provide autonomous continuation/scheduling, tell the user the performance requires continued agent turns or the Codex autopilot command.
